# `tools/host/` — общая машина команды

Несколько ролей собирают мод и запускают игру на одной машине. Три вещи без этих скриптов сталкиваются:

- **сборка:** UnrealBuildTool держит одну блокировку на движок, и вторая сборка не ждёт, а падает с `ConflictingInstance`;
- **игра:** общая установка Steam одна, чужой незагрузившийся мод останавливает запуск у всех;
- **замеры:** чужая игра рядом портит кадровое время.

| Скрипт | Что делает |
|---|---|
| `verify-pr.sh <Мод>...` | **Протокол для PR:** собирает моды под Win64 Shipping, ставит в личную копию игры, запускает под Proton и печатает блок Markdown для вставки в PR. Без этого блока ревью не начинается (решение King 11.11.2026) |
| `build-mod.sh <Мод>` | Сборка одного мода под общей очередью: редактор Linux (его модулями идёт cook), затем Win64 Shipping и упаковка. Исходники берёт из `mod/<Мод>` репозитория, если мод там есть |
| `run-game.sh --mod <архив>...` | Запуск игры в личной копии роли с отдельным префиксом Proton; `--exclusive` — для замеров, один на машине |
| `with-lock.sh build -- <команда>` | Любая другая тяжёлая команда под той же очередью: сборка редактора, `UnrealEditor-Cmd`, cook |
| `selftest.sh` | Самопроверка без движка и игры: заглушки UAT и Flatpak, 26 проверок веток отказа и очередей |
| `lib.sh` | Общие функции |

## Настройка

```bash
export FICSITAI_SML_PROJECT="$HOME/Projects/SML-<роль>"     # личная копия Starter Project, ENVIRONMENT.md §5
export FICSITAI_SML_ZIP="<проект SML>/Saved/ArchivedPlugins/SML/SML-Windows.zip"   # нужен один раз, для личной копии игры
```

Роль берётся из ветки `work/<роль>`; на другой ветке задайте `FICSITAI_ROLE`. Скрипты выполняются на хосте, а не в песочнице сессии.

## Что где лежит

- Очереди: `/tmp/ficsitai-locks/`. `build.lock` — одна сборка на машину; под ней идут приведение исходников к репозиторию, UAT и копирование архива в каталог прогона. `role-<роль>.lock` — одна работа с личной копией игры на роль: установка модов, запуск, сохранение журнала. `game.lock` — запуски игры разных ролей: обычные идут вместе, `--exclusive` ждёт остальных и не пускает новые. Кто держит очередь, написано в файле `.holder` и в сообщении ожидающему.
- Личная копия игры и префикс: `~/.var/app/com.valvesoftware.Steam/Projects/ficsitai-<роль>/{game,compat}`. Копия сделана жёсткими ссылками и места не занимает; при обновлении игры в Steam пересоздаётся сама. Общую установку скрипты не меняют.
- Результаты прогонов и копии собранных архивов: там же, `runs/` и `builds/`. Протокол ставит в игру копию архива из каталога прогона, а не файл из `Saved/ArchivedPlugins`, который перезапишет следующая сборка.

## Границы

- Без роли и без полученной блокировки скрипты ничего не меняют и выходят с ошибкой.
- Очередь действует только на тех, кто запускает через эти скрипты. Сборку мимо очереди `build-mod.sh` пережидает повторами, но сам её не остановит.
- Число процессов компиляции шейдеров (по умолчанию 5, `FICSITAI_SHADER_WORKERS`) передаётся в cook; на сборке с настоящей компиляцией шейдеров ещё не проверено.
- Протокол проверяет, что мод собирается и загружается до главного меню без критических ошибок. Главное меню определяется по двум строкам журнала CL 517554: загрузка карты меню завершена и виджет главного меню заработал. Он не проверяет сохранение, поведение в мире, EGS-сборку в игре и Windows.
- Игра запускается без клиента Steam и остаётся в офлайне; окно появляется на рабочем столе машины.

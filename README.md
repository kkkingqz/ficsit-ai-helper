# FICSIT AI Helper

Мод к Satisfactory и локальный сервис-компаньон, делающие [FICSIT Foreman](https://github.com/StuartMeeks/ficsit-foreman)
инженерным помощником прямо в игре: AI Terminal, экипируемый AI Assistant, производственные
планы, HUD и запросы на создание Blueprint.

**Статус: только архитектура.** Кода пока нет. Репозиторий содержит проект архитектуры
релизной версии, вынесенный на согласование, — не описание реализованного продукта.

## Главное из архитектуры

- **Целевой стек:** Satisfactory 1.2, SML 3.12, Windows game client.
- **Топология:** только одиночная игра. Мультиплеер и Dedicated Server — вне v1.x (v2.0).
- **Два рантайма:** игровой процесс (презентационный слой, authority-слой, локальный
  MCP-эндпойнт на loopback) и локальный Foreman как внешний сервис, который не форкается.
- **Объём v1.0:** ручной контур (планировщик, таблица, read-only граф, dashboard, HUD,
  персистентность) плюс текстовый чат. Blueprint Builder — v1.1, AI-экраны — v1.2,
  голос — v1.3, интерактивный редактор графа — v1.4.
- **Четыре контракта:** `GameCatalog`, `ProductionPlan`, `ScreenDefinition`, `BlueprintRequest`.
- **Граница доверия LLM:** модель предлагает, authority-слой валидирует, игрок подтверждает;
  никакого исполняемого кода от LLM.
- **Работа без LLM:** все ручные функции работают при остановленном сайдкаре (FR-10).

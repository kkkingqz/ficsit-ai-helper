# S8 · Страница нагрузки терминала

Страница для замеров по [чек-листу Gf2, §5.1](../../../tests/test-plan/s8-checklist.md). В ней два графика с двумя рядами на каждом, восемь плиток метрик и таблица на 12 строк. Детерминированная телеметрия обновляется с интервалом 1000 мс. Цвета и размеры взяты из [токенов D-2](../../../docs/team/Gs2.md#d-2--токены-стиля-неделя-1).

## Собрать и открыть

Из корня репозитория:

```sh
python3 web/spikes/s8/pack.py /path/to/new/s8
```

Сборщик на Python 3 скачивает закреплённый релиз [uPlot 1.6.32](https://github.com/leeoniya/uPlot/releases/tag/1.6.32), проверяет SHA‑256 и кладёт библиотеку с лицензией в `third_party/uplot/` внутри поставки. Для сборки без сети передайте `--archive /path/to/uplot-1.6.32.tgz`. Выходной каталог должен быть новым, а его родитель уже существовать.

Откройте `load.html` из собранного каталога. Для BLUI перенесите каталог целиком и загружайте тот же `load.html` через настроенную Co схему `local://`. Страница использует локальные ресурсы и работает при выключенном сайдкаре.

- Штатная нагрузка — 60 точек на ряд. `?points=300` и `?points=600` задают стресс-режимы. Режим также выбирается в поле **History**.
- Размер окна задаёт стенд. Для замера по §5.2 используют 1280 × 720 и 1920 × 1080. Для конфигурации с тремя браузерами каждому передаётся один и тот же режим.
- Проверка в Chrome на хосте: `python3 web/spikes/s8/smoke_test.py /usr/bin/google-chrome`. Замеры кадрового времени, памяти и работы `local://` выполняются в S8 на игровом стенде.

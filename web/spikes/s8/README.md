# S8 · Страница нагрузки терминала

Страница для замеров по [чек-листу Gf2, §5.1](../../../tests/test-plan/s8-checklist.md). В ней два графика с двумя рядами на каждом, восемь плиток метрик и таблица из 12 генераторов, сгруппированных по типу. В заголовке каждой группы видны число работающих генераторов и их суммарная выдача. Детерминированная телеметрия обновляется с интервалом 1000 мс. Цвета и размеры взяты из [токенов D-2](../../../docs/team/Gs2.md#d-2--токены-стиля-неделя-1).

## Собрать и открыть

Из корня репозитория:

```sh
python3 web/spikes/s8/pack.py /path/to/new/s8
```

Сборщик на Python 3 скачивает закреплённый [архив uPlot 1.6.32 из npm](https://registry.npmjs.org/uplot/-/uplot-1.6.32.tgz), проверяет SHA‑256 и кладёт библиотеку с лицензией в `third_party/uplot/` внутри поставки. Для сборки без сети передайте `--archive /path/to/uplot-1.6.32.tgz`. Выходной каталог должен быть новым, а его родитель уже существовать.

В Chrome откройте `load.html` из собранного каталога. Для BLUI распакуйте весь каталог в `Web/spikes/s8/` плагина и откройте `https://ficsitai.invalid/spikes/s8/load.html`. Ресурсы отдаёт локальный обработчик CEF. Относительные ссылки на CSS, JS и uPlot ведут в тот же каталог. Страница работает при выключенном сайдкаре. [Подтверждение Co](../../../docs/team/questions/Co.md)

- Штатная нагрузка — 60 точек на ряд. `?points=300` и `?points=600` задают стресс-режимы. Режим также выбирается в поле **History**. При автоматических замерах передавайте `?points=` в URL.
- Размер окна задаёт стенд. Для замера по §5.2 используют 1280 × 720 и 1920 × 1080. Для конфигурации с тремя браузерами каждому передаётся один и тот же режим.
- Проверка в Chrome на хосте: `python3 web/spikes/s8/smoke_test.py /usr/bin/google-chrome`. Запуск через обработчик CEF и замеры кадрового времени и памяти проверяются в игре.

## Прозрачный HUD для конфигурации D

Откройте `load.html?overlay=1` или `https://ficsitai.invalid/spikes/s8/load.html?overlay=1`. В верхнем левом углу три плитки D-2 с генерацией, потреблением и запасом до лимита. Они обновляются по той же детерминированной телеметрии раз в секунду. За плитками фон прозрачный. Страница не создаёт графики и таблицу, интерактивные элементы отсутствуют.

Для [конфигурации D](../../../tests/test-plan/s8-checklist.md) хост должен сохранять альфа-канал текстуры, не перехватывать ввод игры в фоновом режиме и открывать интерактивную страницу по горячей клавише. Прозрачность страницы и обновление плиток проверяет дымовой тест Chrome. Композицию с игрой, ввод и кадровое время проверяют на стенде под Proton.

## Прокрутка панели

Подключите `scroll-panel.css`. Разместите постоянный заголовок и область `.scroll-panel__body` внутри `.scroll-panel`. Дайте области имя через `aria-labelledby` и добавьте `tabindex="0"` для прокрутки клавиатурой. Родитель ограничивает высоту панели доступным местом. В раскладке с автоматической высотой задайте предел через `--scroll-panel-limit`. Если часть содержимого должна оставаться на виду, добавьте `.scroll-panel__sticky` к её верхнему блоку, например `thead`.

# `screens/api` — фасад публичного API мода

Один интерфейс для экрана в двух средах: в игре фасад идёт **мостом** к `FicsitAIApi`, в браузере — **HTTP** к dev-серверу. Экран пишется один раз и отлаживается без игры (ARCHITECTURE §13, ADR-026, ADR-032; S6, [#12](https://github.com/kkkingqz/ficsit-ai-helper/issues/12)).

```js
import { createApi } from "@ficsitai/screens-api";

const api = createApi();              // транспорт выбирается по среде
const status = await api.getStatus();
const value = await api.queryMetric({ metricId: "power.production" });
api.on("metrics.snapshot", () => redraw());
```

## Что фасад делает и чего не делает

Он тонкий нарочно. Всё, что он добавляет к контракту, — выбор транспорта, единая форма ошибки и типы.

- **Не придумывает данные.** Ни кэша, ни значений по умолчанию, ни повторов запроса. Где экран показывает прочерк — прочерк и пришёл: `state: "notApplicable"`, `value: null` (правило Gs-13 контракта).
- **Не перекладывает формы.** Ответ типизирован, но это тот же объект, что пришёл. Вторая форма стала бы второй правдой при каждой правке контракта.
- **Не хранит состояние мода.** Статус спрашивают, события приходят; что из этого показать — дело экрана.
- **Не знает про чат.** Запросы чата появятся в API вместе с мостом (минорная 0.5.0, Co-82); тогда к фасаду добавятся `chatSend`, `chatCancel`, `chatHistory`.

Формы, коды ошибок и семантика — из [public-api-v0.md](../../../docs/interfaces/public-api-v0.md). При расхождении прав документ, а не этот пакет: контракт задаёт Co, утверждает Gs.

## Транспорты

| Среда | Как работает |
|---|---|
| Игра | `blu_event("ficsitai.bridge", { id, op, args })`, ответ — `window.__ficsitaiBridge.receive({ re, body \| error })`, события — `{ event, data }` ([конверт моста](../../../docs/interfaces/web-runtime-plugin.md#конверт--для-фасада-co2)) |
| Браузер | `POST /api/v0` с тем же конвертом, события — `text/event-stream` на `/api/v0/events` |

Конверт нарочно один и тот же: экран, отлаженный в браузере, не встречает в игре другой формы, а разница между средами остаётся в одном файле на транспорт.

Три правила моста соблюдает фасад, а не мод:

1. **`id` уникален на странице** — случайный префикс плюс счётчик, поэтому ответ прежней страницы после перезагрузки не попадёт в новую.
2. **Предел 64 КиБ проверяется до отправки.** Конверт больше мод отбрасывает молча, и запрос без этой проверки висел бы вечно. Отказ — `TOO_LARGE`, локально.
3. **Ответ с незнакомым `re` пропускается** — так выглядят ответы после перезагрузки или после срока; их видно в `window.__ficsitaiBridge.stray`.

Своего срока у моста нет, поэтому срок держит фасад: по замерам S8 мост отвечает за кадр (медиана 13 мс), так что молчание дольше секунд — это потеря, а не медленная работа. Без срока экран замирал бы молча.

## Dev-сервер

```bash
npm run build
node dist/dev/cli.js --root web/screens --port 5173            # источник demo
node dist/dev/cli.js --root web/screens --source ./my-source.js # свой источник
```

- `POST /api/v0` — запросы API v0 тем же конвертом, что на мосту;
- `GET /api/v0/events` — события источника плюс `reload` при правке файла;
- `GET /api/v0/reload.js` — клиент горячей перезагрузки, подключается строкой `<script src="/api/v0/reload.js"></script>`;
- остальное — статика из `--root`, без кэша (иначе горячая перезагрузка бессмысленна).

**Источник — это объект с пятью методами API v0** (`src/dev/source.ts`). Сервер их не содержит, а подключает: модуль из `--source` экспортирует `createSource()`. Так наборы Fixture и проигрыватель Recording (Gf2) и источник Save (Cf3, `sidecar/save-source/`) приезжают без правки сервера.

Встроенный источник `demo` — **не замена наборам Fixture**. В нём ровно столько, сколько нужно для проверки самого фасада: значение, неприменимое значение, ряд с пропуском, области с пагинацией и все коды ошибок контракта. Подменять им наборы нельзя: разойдутся две правды о том, что значит «пустая фабрика».

## Пример

`example/index.html` — страница на фасаде: статус, каталог, значения и перерисовка по событию снимка. Она же проверка связки в браузере:

```bash
node dist/dev/cli.js --root . --port 5173
# http://127.0.0.1:5173/example/index.html
```

## Проверки

`npm run typecheck`, `npm run build`, `npm test` — 23 проверки.

`test/bridge.test.ts` держит мост: конверт и канал, уникальность `id`, отказ `TOO_LARGE` до отправки, пропуск чужого `re`, ошибка мода кодом контракта, срок вместо вечного ожидания, события, выбор транспорта и расхождение мажорной версии в статусе (по §5.5 оно не исключение: ручные функции продолжают работать).

`test/dev-server.test.ts` держит браузерную сторону: формы статуса, каталога, значения и ряда, неприменимое значение прочерком, пропуск в ряду по `timestamps`, пагинация областей и невзаимозаменяемость курсоров, коды `UNKNOWN_METRIC`, `SCOPE_REQUIRED`, `SCOPE_NOT_FOUND`, `SERIES_NOT_AVAILABLE`, `INVALID_ARGUMENT`, `UNKNOWN_OP`, раздача страниц и отказ выйти за корень, горячая перезагрузка по правке файла и событие снимка до подписчика фасада.

Связка проверена в браузере целиком: страница открыта с dev-сервера, значения пришли, правка файла перезагрузила вкладку, событие снимка дошло до страницы.

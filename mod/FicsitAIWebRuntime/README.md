# `FicsitAIWebRuntime` — мод-библиотека встроенного браузера

BLUI (форк getnamo, v5.1.0, MIT) и CEF 128 отдельным модом-библиотекой: основной мод объявляет её зависимостью, менеджер модов ставит вместе с ним. Вынесена отдельно не ради размера поставки (он ограничением не считается), а чтобы CEF обновлялся независимо от мода — ARCHITECTURE §6.3.1.

**Каталог наполняется только если ADR-032 принят** на воротах W (конец недели 3) по итогам спайка S8 ([#8](https://github.com/kkkingqz/ficsit-ai-helper/issues/8)). При отклонении экраны остаются на UMG, а этот каталог и `web/` не нужны — вместо них `screenlab/`.

Исходники BLUI вендорятся в [`third_party/blui/`](../../third_party/blui/), здесь — только сборка плагина-мода и `RuntimeDependencies` для бинарников CEF.

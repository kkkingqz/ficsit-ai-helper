# Спецификация тестовых сохранений (P-5, #6)

Сохранения с известным состоянием фабрики необходимы для верификации каталога контента (S3), профилирования бюджета GameThread телеметрии (V-09) и отладки адаптера без запуска игры (S6 / Save-источник).

> [!IMPORTANT]
> Файлы сохранений (`.sav`) в git-репозиторий **не коммитятся** (бинарные файлы большого объёма). В репозитории хранятся только метаданные, описание фабрик и хэш-суммы файлов. Сами файлы размещаются локально на машине разработки или по защищённой ссылке King.

---

## 1. Четыре профиля тестовых сохранений

### Save A · Раннее сохранение (Starter Base)
- **Целевой масштаб:** до 500 построек.
- **Назначение:** базовая функциональность `CatalogProvider` на начальных этапах игры, проверка пустого/минимального состояния телеметрии.
- **Требования к фабрике:**
  - Фаза Space Elevator: Tier 1–2 (начало игры);
  - Энергетика: 1–2 биогенератора или начальная угольная станция (до 4 генераторов);
  - Производство: базовое железо, медь, бетон;
  - Постройки: конструкторы, плавильни, несколько конвейеров Mk.1.
- **Ожидаемый `saveId`:** создаётся модом при первой загрузке.

---

### Save B · Средняя фабрика (Mid-game, 1 000 – 2 000 построек)
- **Целевой масштаб:** 1 000 – 2 000 построек.
- **Назначение:** основной тестовый стенд для замеров кадрового времени Spike S8 и отладки сборщиков телеметрии Spike S3.
- **Требования к фабрике:**
  - Фаза Space Elevator: Tier 5–6 (нефть, сталь);
  - Энергетика:
    * Угольная электростанция (8+ угольных генераторов) и топливная электростанция (4+ топливных генераторов);
    * Наличие подключённого блока аккумуляторных батарей (Power Storage) в частично заряженном состоянии (для проверки расчёта $T_{\text{drain}}$ и статуса разряда);
    * Выключатель питания (Power Switch) для контролируемого отключения секции сети.
  - Производство: базовые детали, стальные трубы/балки, модульные каркасы, пластик, резина.
  - Жидкости: вода, сырая нефть, мазут (для проверки конверсии единиц $1\ \text{м}^3 = 1000$ внутренних единиц).
  - Логистика: конвейеры Mk.3/Mk.4, трубы, грузовые станции или тракторы.

---

### Save C · Поздняя мегабаза (End-game Megabase, 5 000+ построек)
- **Целевой масштаб:** от 5 000 до 15 000+ построек.
- **Назначение:** стресс-тестирование индекса построек, проверка устойчивости `buildingId`, замеры соблюдения бюджета GameThread телеметрии ($\le 2.0$ мс при нарезке по кадрам) по критерию V-09.
- **Требования к фабрике:**
  - Фаза Space Elevator: Tier 8–9 (ядерная энергетика, алюминий, электроника);
  - Энергетика: сложная разветвлённая глобальная сеть, ядерные генераторы, геотермальные генераторы, крупный массив батарей;
  - Производство: тяжелые модульные каркасы, компьютеры, турбомоторы, переработка ядерных отходов;
  - Логистика: развитая сеть поездов (железные дороги, станции), дроны.

---

### Save D · Сохранение с модом на рецепты (Modded Recipes)
- **Целевой масштаб:** 1 000+ построек с активным сторонним модом на рецепты.
- **Назначение:** проверка отказоустойчивости `CatalogProvider` при наличии кастомных рецептов и предметов, зарегистрированных сторонними модами (проверка отсутствия крашей и корректности статуса разблокировки).
- **Требования к фабрике:**
  - Сохранение создано с активным популярным модом из Satisfactory Mod Repository (например, мод на расширенные рецепты или дополнительные здания);
  - На фабрике установлены машины, производящие предметы по модовым рецептам.

## 2. Каталог размещения файлов сохранений

Локальные файлы сохранений размещаются на машине разработки по стандартному пути игры:

```
~/.local/share/Steam/steamapps/compatdata/526870/pfx/drive_c/users/steamuser/AppData/Local/FactoryGame/Saved/SaveGames/<SteamID64>/
```

Или в локальном каталоге для отладки адаптера:
```
fixtures/saves/
├── save_a_starter.sav
├── save_b_midgame.sav
├── save_c_megabase.sav
└── save_d_modded.sav
```
*(Каталог `fixtures/saves/` добавлен в `.gitignore`)*

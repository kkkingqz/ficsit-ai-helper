# `fixtures/` — данные для отладки без игры

Источники API, которыми экраны и адаптер проверяются вне игры (ARCHITECTURE §8.5, ADR-025).

- **Описания тестовых сохранений** (P-5, [#6](https://github.com/kkkingqz/ficsit-ai-helper/issues/6)): раннее, среднее на 1–2 тыс. построек, позднее на 5 тыс.+, с модом-рецептами. Сами `.sav` в репозиторий не кладём — здесь состав и где взять.
- **Наборы Fixture:** пустая и большая фабрика, сайдкар недоступен, инертный режим, нет питания.
- **Записи Recording** (JSONL) для проигрывателя с перемоткой.

Ведёт Gf2; состав сохранений — King.

# `tests/` — тесты вне кода модулей

- Сценарии **fake-LLM** и тесты адаптера.
- **Автотесты экранов** на наборах Fixture в браузере.
- **Протоколы замеров:** кадровое время телеметрии, задержка круга BLUI, время до первого ответа сайдкара.
- **Тест паритета:** падает, если операция выставлена модели без ручной точки входа (V-05, AC-21).

Тесты `core/` на хосте живут рядом с кодом и собираются через CMake. Ведёт Gf2, чек-листы — из тест-плана P-7 ([#32](https://github.com/kkkingqz/ficsit-ai-helper/issues/32)).

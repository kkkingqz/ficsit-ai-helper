# Чек-листы критериев приёмки вертикального среза v0.1 (V-01…V-11)

Настоящий документ детализирует критерии приёмки среза v0.1 ([`PLAN-v0.1.md §2`](../../docs/PLAN-v0.1.md)) и критерии приёмки v1.0 ([`ARCHITECTURE.md §14`](../../docs/ARCHITECTURE.md)) в проверяемые пункты.

Проверка критериев выполняется **Gf2** на воротах **G1** (конец недели 5) и **G2** (неделя 9 перед выпуском закрытой альфы).

## Детальные чек-листы критериев

### V-01 · AI Terminal и каркас хоста
- [ ] Игрок открывает меню строительства, находит AI Terminal в списке построек (категория мода).
- [ ] Стоимость строительства списывается корректно; объект успешно размещается в мире.
- [ ] При подключении к электросети терминал потребляет ровно 10 MW мощности.
- [ ] При взгляде на терминал и нажатии `E` открывается интерактивное окно с навигацией: вкладки «Чат с ИИ» и «Статистика».
- [ ] При отключении кабеля питания терминал гаснет; повторное нажатие `E` показывает статус «нет питания» без открытия модулей.
- [ ] Экранная поверхность меша терминала отображает заглушку с соотношением сторон 16:9 без геометрических искажений (ADR-030).

### V-02 · Экран «Статистика»
- [ ] Раздел «Энергия» отображает:
  - Текущее производство и потребление электроэнергии в MW;
  - Ёмкость и максимум потребления по сетям;
  - Генераторы, сгруппированные по типам (угольные, топливные и др.);
  - Батареи: процент заряда, время до полного заряда / разряда;
  - Индикацию срабатывания предохранителя сети.
- [ ] Раздел «Ресурсы» отображает:
  - Производство предметов в минуту (`items/min`);
  - Потребление предметов в минуту (`items/min`);
  - Жидкости в кубических метрах в минуту (`m3/min`);
  - Баланс (дельта производство − потребление).
- [ ] Все значения имеют метку источника (`live`) и время актуальности. При задержке данных значения приглушаются с меткой `stale`.
- [ ] Графики временных рядов переключаются между интервалами: **5 минут**, **15 минут**, **60 минут** от начала сессии.
- [ ] После перезапуска игры график начинается с момента старта сессии; UI сообщает об этом информационным сообщением, а не ошибкой.

### V-03 · Экран «Чат с ИИ»
- [ ] Ввод текста в поле чата и отправка по Enter / кнопке отправляет запрос модели.
- [ ] Ответ модели выводится потоком (streaming / токен за токеном).
- [ ] Кнопка отмены активна во время генерации; нажатие отмены немедленно прерывает поток и оставляет сгенерированный фрагмент.
- [ ] История диалога сохраняется в локальной базе данных Foreman и восстанавливается при переоткрытии окна.
- [ ] При незапущенном или аварийно упавшем сайдкаре экран чата показывает статус «не подключено» с инструкцией по запуску сайдкара. Игра при этом не блокируется.

### V-04 · Модельные операции и белый список инструментов
- [ ] Модель имеет доступ строго к инструментам белого списка: `list_metrics` и `query_metric`.
- [ ] Инструменты Foreman (`sf-mcp`), позволяющие совершать произвольные действия вне мода, для модели скрыты.
- [ ] При запросе пользователя о состоянии завода («Сколько энергии производит фабрика?») модель корректно вызывает `query_metric` с валидными параметрами и включает полученные живые числа в ответ.
- [ ] Модель не имеет инструментов, модифицирующих игровой мир (ADR-009).

### V-05 · Паритет ручного пути и модели
- [ ] Любая операция, доступная модели (`list_metrics`, `query_metric`), имеет ручной аналог в интерфейсе: игрок может вручную выбрать метрику и временное окно в «Статистике» и увидеть те же данные.
- [ ] Вызов операции из UI и вызов через инструмент модели с одинаковыми параметрами возвращают идентичные контрактные данные.
- [ ] Тест паритета в CI (`check-invariants.sh` и автотест V-3) падает, если в реестр операций добавляется инструмент без зарегистрированной ручной точки входа в UI.

### V-06 · Устойчивость к сбоям сайдкара (Деградация)
- [ ] Принудительная остановка процесса сайдкара (`kill -9`) во время активной игры не приводит к зависанию (freeze) или падению (crash) игрового процесса.
- [ ] Экран «Статистика» продолжает отображать локальную телеметрию из мода.
- [ ] Экран «Чат» корректно переключается в состояние «не подключено».
- [ ] При повторном запуске сайдкара связь восстанавливается автоматически без перезапуска игры.

### V-07 · Инертный режим в мультиплеере
- [ ] Загрузка сохранения в режиме кооперативной сетевой игры (Multiplayer / Friends Only) переводит мод в инертный режим:
  - Терминал отображает статус «Инертный режим: мультиплеер не поддерживается в v0.1»;
  - Сетевой канал к сайдкару закрыт;
  - Фоновые сборщики телеметрии приостановлены.
- [ ] При подключении второго игрока к одиночной сессии мод автоматически переходит в инертный режим.
- [ ] Игрок без установленного мода не может подключиться к сессии (блокировка на уровне SML `RequiredOnRemote`).
- [ ] Сохранение игры в инертном режиме не повреждает `saveId` и данные фабрики.

### V-08 · Установка и тихий запуск на Windows (Пилотный тестер)
- [ ] Установка мода: мод устанавливается через Satisfactory Mod Manager (SMM) в один клик с зависимостью `FicsitAIWebRuntime`.
- [ ] Установка сайдкара: архив распаковывается в любую пользовательскую папку.
- [ ] Первый запуск: лаунчер запрашивает только выбор провайдера LLM и ключ API; правка конфигурационных файлов вручную не требуется.
- [ ] **Критерий брандмауэра:** Брандмауэр Windows не выдаёт диалоговых окон с запросом сетевых разрешений (все сервисы слушают только `127.0.0.1`).
- [ ] Время от распаковки архива до получения первого ответа в игровом чате составляет менее 5 минут.

### V-09 · Бюджет GameThread
- [ ] Профилирование игры с помощью Unreal Insights / `stat Unit` на тестовом сохранении фабрики в несколько тысяч построек (P-5).
- [ ] Нагрузка от сбора телеметрии мода не превышает **2.0 мс** на GameThread в среднем и **3.5 мс** в пике.
- [ ] Сборка телеметрии нарезана по кадрам (time-sliced), фризы кадра (micro-stutters) отсутствуют.

### V-10 · Зелёный CI
- [ ] GitHub Actions пайплайн полностью зелёный:
  - Валидация примеров контрактов по JSON Schema (`contracts.yml`);
  - 5 правил архитектурных инвариантов (`invariants.yml`);
  - Тесты ядра `core/` на хосте через CMake;
  - Интеграционные тесты адаптера с fake-LLM;
  - Автоматический тест паритета операций.

### V-11 · Экраны вне игры
- [ ] Экраны «Статистика» и «Чат» успешно запускаются и функционируют без запуска Satisfactory:
  - В браузере (при принятии ADR-032) на dev-сервере;
  - Либо в приложении Screen Lab на стандартном UE 5.6 (при откате на UMG).
- [ ] Поддерживаются источники данных: Fixture (эталонные статические наборы данных), Save (разбор файла `.sav` без игры) и Recording (воспроизведение сессии с перемоткой).
- [ ] Модуль `FicsitAIUI` компилируется без заголовков игры и SML.

## Проверки

- **Секции между LOD**: имена слотов LOD1/LOD2 — подмножество LOD0 своего меша ✅; при импорте LOD сопоставляются с секциями LOD0 по имени материала (у LOD2 экстерьера нет стекла и мелких слотов — это нормально).
- **Упрощение LOD1/LOD2 не трогает** декали, экраны, полосы и эмиссив (защищённые слоты M_Decal, M_ScreenStatic, M_ScreenRT, M_Hazard, M_LightWarm, M_Beacon, M_Holo): схлопывание рёбер только на тайлинговых слотах, UV атласов не уезжают в соседние ячейки.
- **Коллизия**: 28 выпуклых частей, все выпуклые и ≤ 256 вершин ✅.
- **Проходимость** (капсула r 0,3 м, тело от 0,5 до 1,8 м над поверхностью, шаг ступени UE 0,45 м; маршрут дверь → лестница → пульт → проектор → группа обслуживания → техстена): свободно ✅.
- **Герметичность**: лучи из центра комнаты наружу сквозь переднюю стену, стекло, боковые стены, заднюю стену рядом с дверью и крышу — все упираются в коллизию ✅.
- **Пол**: точек пола без коллизии (сетка 0,5 м, кроме лестничного приямка) — 0 ✅.
- **Сокеты** в `SM_CommandCenter.fbx`: `SOCKET_power`, `SOCKET_interact`, `SOCKET_ui_camera`, `SOCKET_holo`, `SOCKET_door`.
- **Для BP**: `SM_CommandCenter_ScreenRT` — главный экран отдельным мешем (обычный компонент, динамический материал с render target); `SM_CommandCenter_HoloSpin` — вращающаяся часть голограммы, опорная точка = `SOCKET_holo` (компонент крепится к сокету без смещения); `SM_CommandCenter_Holo` — статическая часть (лучи, шкала, диск, линзы).
- Вырожденные грани-иглы после булевых операций (высота < 1 мм): **847 → 0**.
- Clearance: `clearance.json` (16 × 8 × 7.6 м, без антенны).
- Нормали: жёсткие рёбра по углу 30°, взвешенные нормали (по площади, keep sharp), триангуляция с сохранением нормалей, касательные в FBX.

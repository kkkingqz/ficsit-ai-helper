# Satisfactory — Центр управления. Пакет визуальных референсов

Назначение: концептуальная основа для ручного 3D-моделирования в Blender/UE. Это НЕ готовые CAD-чертежи, технические развёртки или точные изображения взаимно согласованной геометрии. AI-сгенерированные ортогональные виды могут расходиться в отдельных деталях.

## Иерархия референсов
1. `00_approved_concept.png` — главный художественный эталон, одобренный вариант.
2. `01_exterior_reference.png` — силуэт, фасады, основа без лестницы.
3. `02_interior_reference.png` — консоль, экраны, голографический постамент.
4. `03_modular_parts.png` — потенциальное разделение геометрии на отдельные меши.
5. `04_blockout_materials.png` — визуальные пропорции и ориентиры для материалов.
6. `05_full_technical_concept.png`, `06_full_detail_concept.png` — исходные сгенерированные технические композиции.

## Неподвижные требования дизайна
- Компактное одноэтажное здание на низком модульном промышленном основании. Лестницы нет.
- Оранжевый каркас с большими скосами, тёмные металлические стены и широкое переднее остекление.
- Панорамный фронтальный/диагональный оконный блок из отдельных стеклянных сегментов с видимыми рамами.
- Внутри: длинный многомониторный пульт (верхние дисплеи + нижние консоли) и отдельный компактный голографический стол.
- Вентиляция, трубы, маяк/антенна, встроенный свет, подсветка, предупреждающие чёрно-жёлтые полосы.

## Предлагаемое разделение на отдельные mesh
BASE, FLOOR, MAIN_SHELL, CORNER_ARMOR, ROOF, WINDOW_FRAMES, WINDOW_GLASS, BACK_PANEL, SIDE_PANEL, CONSOLE_BODY, DISPLAY_FRAMES, DISPLAY_PLANES, CONTROL_PANELS, HOLO_PEDESTAL, HOLO_EMITTER, EXHAUST_PIPES, VENTS, BEACON, LIGHTS, DECALS.

## Материалы
- Оранжевая окрашенная панель (dielectric, paint, medium roughness).
- Тёмный шероховатый металл, средне-серый окрашенный металл, тёмная резина.
- Отдельный материал полупрозрачного стекла.
- Эмиссивные материалы: голубая голограмма, тёплый белый свет, дисплеи и сигнальные маяки.

## Точность и масштаб
Различные изображения содержат НЕСОВПАДАЮЩИЕ иллюстративные размеры (например 6×4 м против 12×6 м). НЕ использовать напечатанные цифры как исходную CAD-истину. Сначала построить общий blockout и выбрать единый масштаб, затем согласовать виды. У Satisfactory обычный фундамент 8×8 м; сетка и габариты будущего размещаемого объекта — отдельное проектное решение.

## Рекомендуемый порядок
Blockout → согласование силуэта с главным концептом → корпус и окна → пульт → голографическая платформа → разборка на reusable meshes → UV/trim sheet → материализация и LOD.

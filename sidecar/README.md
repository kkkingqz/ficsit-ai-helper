# `sidecar/` — локальный сайдкар

Vanilla [FICSIT Foreman](https://github.com/StuartMeeks/ficsit-foreman) плюс наш тонкий адаптер. **Foreman не форкается и не патчится** (ADR-012): расхождения гасятся в адаптере, в одном месте. Коммит Foreman зафиксирован — его обновление идёт отдельной задачей (R-17).

| Каталог | Что внутри |
|---|---|
| `adapter/` | Node 22 + MCP TypeScript SDK: единственный `MCP_URL` Foreman, инструменты из реестра, белый список, `apiVersion`, канал к моду, источник Save |
| `launcher/` | запуск `ff-server`, `sf-mcp` и адаптера на `127.0.0.1`, генерация секретов и токена, сборка архива без установщика |

Всё слушает только `127.0.0.1`: у `ff-server` и `sf-mcp` по умолчанию `HOST` и `MCP_HTTP_HOST` стоят на `0.0.0.0`, а брандмауэр Windows не должен спрашивать разрешений (V-08, AC-12).

Ревью: контрактная поверхность адаптера — инструменты из реестра, белый список, `apiVersion`, формат канала — проходит ревью (с 10.11.2026 ревьюер Gs, King передал ему очередь Co). Лаунчер и сборка архива ревью не проходят, вместо него чек-лист Gf2 и тесты с fake-LLM (решение King 09.11.2026).

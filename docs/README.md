# FICSIT AI — Release Architecture v2.0-draft

Дата: 04.11.2026. Заменяет v1.0-draft того же числа.

## Состав

- `ARCHITECTURE.md` — архитектурный документ (источник истины).
- `assets/*.dot` — редактируемые исходники схем Graphviz.
- `contracts/*.json` — примеры предлагаемых контрактов (не готовое runtime API).

## Главное изменение относительно v1.0-draft

Проект отказывается от мультиплеера и Dedicated Server в пределах v1.x. Это убрало
с критического пути все интеграционные неизвестные, способные опрокинуть архитектуру:
сетевой канал между внешним сервисом и игровым сервером, доставку Blueprint клиенту
в отсутствие локального игрока, репликацию экранов и ACL.

Следствия: пять рантаймов сократились до двух (игровой процесс и локальный сайдкар),
Game Bridge удалён, Ficsit Remote Monitoring больше не обязательная зависимость,
объём v1.0 сужен до ручного контура плюс текстовый чат.

Полная сводка изменений с причинами — раздел 17 документа.

## Сборка схем и документа

PNG в комплект не входят — исходники `.dot` изменились и требуют перерисовки:

```
dot -Tpng -Gdpi=150 assets/components.dot -o assets/components.png
dot -Tpng -Gdpi=150 assets/actions.dot    -o assets/actions.png
```

Форматированный документ (ссылки на изображения в `ARCHITECTURE.md` уже проставлены):

```
pandoc ARCHITECTURE.md -o FICSIT_AI_Release_Architecture_v2.0.docx
```

## Статус

Документ описывает предлагаемые решения на согласование, а не реализованный продукт.
Помечены: действующие риски (15.2), риски, закрытые решением об одиночной игре (15.1),
риски, отложенные вместе с версиями (15.3), и открытые лицензионные вопросы (2.2).

Блокирующие проверки до начала работ: лицензия Ficsit Remote Monitoring (R-12),
осуществимость входящего MCP-слушателя в игровом процессе (R-13, Spike S2),
оценка трудозатрат и состава команды (R-16).

# FICSIT AI — Release Architecture v2.2-draft

Дата: 09.11.2026. Заменяет v2.1-draft от 05.11.2026.

Лицензия проекта — **GPL-3.0-or-later** (`LICENSE`, §2.2, ADR-031).

## Состав

- `ARCHITECTURE.md` — архитектурный документ (источник истины).
- `MODULES.md` — реестр модулей функционала: готовое решение, лицензия и остаток собственной работы по каждому.
- `assets/*.dot` — редактируемые исходники схем Graphviz.
- `contracts/*.json` — примеры контрактов (не готовое runtime API).
- `contracts/schemas/*.schema.json` — JSON Schema контрактов (draft 2020-12); примеры проверяются по ним в CI.
- `concepts/*.png` — концепт экранов: состав и компоновка, не шаблон (разбор — §6.7–§6.9).

## Главное в 2.2-draft

Редакция сводит две линии, развивавшиеся параллельно от одной базы. Ведущей выбрана 2.1-draft; закрытая линия 3.0-draft сохранена в ветви `docs/architecture-3.0-salvage`. Из неё перенесены находки:

- **Лицензии у Ficsit Remote Monitoring нет** — файла лицензии в репозитории не существует, заимствование не разрешено. R-12 закрыт отрицательно, Spike S3 разблокирован, **телеметрия становится полностью собственной** (§2.2, §8.2).
- **Готовые модули платформы:** Mod Configuration и персистентность `AModSubsystem` из SML, клавиши — Enhanced Input игры, плюс `UModContentRegistry` для состава каталога. Mod Key Bind Registry в SML 3.12 нет, а Replication Policy сторонность сессии не определяет (исправлено 09.11.2026). Единственная вставка, уменьшающая объём v1.0 (§2.3, ADR-027).
- **R-14 закрывается без LP-решателя:** при выбранных игроком альтернативах задача линейна (§8.3, ADR-028).
- **`GameFacade/` с инвариантом CI** — первая конкретная митигация R-10, обобщение ADR-026 (§3.2.1, ADR-029).
- **`vercel/pkg` заархивирован**, Node SEA в Active Development: R-11 повышен (§4.1).
- **Схема страницы результата поиска по каталогу** — он пересекает границу доверия (§5.1).

Решения этой редакции: телеметрия v1.0 — **в пределах сессии**, история 24 ч в v1.1; **«модель не изменяет игровой мир» — постоянный инвариант**, а не объём версии; модель управляет экранами и библиотекой чертежей, **включая удаление чертежей**; **ассет командного центра входит в v1.0** с единственным следствием для контрактов — экраны меша 16:9 (ADR-030).

Ещё два решения приняты после первой правки редакции:

- **Лицензия — GPL-3.0-or-later** (ADR-031). Попутно исправлен факт: SML под GPL-3.0, а не под MIT. Практических следствий два: `piper1-gpl` вернулся в кандидаты TTS, внешние моды обращаются к API без линковки заголовков и потому могут быть под любой лицензией.
- **`clockApplied` удалён из `BlueprintRequest`, `clockPercent` стал необязательным** (§5.4). Прежняя пара была выходом в схеме входа и требовалась обязательной при неизвестном действии; теперь правду о каждом запросе говорит `PreviewResult` кодом `CLOCK_NOT_APPLIED`.

Что из закрытой линии отвергнуто: форк SBC целиком как база мода (ставил проект на репозиторий без внешнего review) и очередь подтверждений игрока (процедурная защита слабее структурной, см. §17.1).

## Решения 2.1-draft, оставшиеся в силе

Сделаны по результатам проверки исходников Foreman, поиска готовых планировщиков и пересмотра объёма v1.0:

- **Адаптер сайдкара** между модом и vanilla Foreman: единственный MCP-сервер Foreman, белый список инструментов, авторизация. Мод подключается к нему исходящим соединением — входящего слушателя в игре нет (ADR-012).
- **Планировщик и представление плана** — стандартизированная обёртка с заглушкой в v1.0; внешний провайдер и UI подключаются позже, первый кандидат — ядро Satisfactory Build Calculator (ADR-013, ADR-007).
- **UI — переиспользуемые экранные модули** (Dashboard, Chat, Notes, Work Orders, Screens); в v1.0 хост — AI Terminal (10 MW), в v1.4 — AI Assistant (ADR-001).
- **Объём v1.0 пересмотрен:** редактор экранов и экранные инструменты модели — в v1.0; дальше v1.1 — Blueprint Builder, v1.2 — голос, v1.3 — планировщик, v1.4 — AI Assistant и HUD.
- **Подтверждений игрока нет:** модель создаёт только объекты мода (заметки, экраны, чертежи в библиотеке), ни одно действие не изменяет мир (ADR-009). В 2.2-draft это усилено до постоянного инварианта.
- **Состояние мода — в сохранении** с идентификатором `saveId` (ADR-014).
- **Мультиплеер** определяется в ходе сессии; контент регистрируется всегда, отключается поведение (ADR-016).
- **Каталог для модели** — поисковые инструменты (ADR-017).
- **Паритет ручного и AI-пути:** каждый инструмент модели — операция общего реестра с ручной точкой входа в UI, работающая без LLM (ADR-018, §7.5).
- **Публичный API мода:** экраны, модель, FicsIt-Networks и другие моды — равноправные клиенты одного API; интеграция с FIN через его reflection-конвенцию, без зависимости (ADR-023, ADR-024).
- **Отладка без игры:** источники данных Live, Save (разбор `.sav` пакетами Foreman), Recording, Fixture; Screen Lab — отдельный UE-проект для экранов (ADR-025, ADR-026).
- Первый результат работ — **вертикальный срез v0.1**: терминал, Chat, Dashboard.

Полная сводка с причинами — раздел 17.1 документа; переход 2.0→2.1 — раздел 17.2, 1.0→2.0 — раздел 17.3.

## Сборка схем и документа

PNG в комплект не входят:

```
dot -Tpng -Gdpi=150 assets/components.dot -o assets/components.png
dot -Tpng -Gdpi=150 assets/actions.dot    -o assets/actions.png
```

Форматированный документ (ссылки на изображения в `ARCHITECTURE.md` уже проставлены):

```
pandoc ARCHITECTURE.md -o FICSIT_AI_Release_Architecture_v2.2.docx
```

Проверка примеров контрактов локально (то же делает CI):

```
cd contracts && npx --yes ajv-cli@5.0.0 validate --spec=draft2020 --strict=true -s schemas/production-plan.schema.json -d plan.example.json
```

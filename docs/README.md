# FICSIT AI — Release Architecture v3.0-draft

Дата: 04.11.2026. Заменяет v2.0-draft того же числа.

## Состав

- `ARCHITECTURE.md` — архитектурный документ (источник истины для решений).
- `MODULES.md` — реестр из 34 модулей функционала: по каждому готовое решение, лицензия,
  статус проверки и остаток собственной работы.
- `contracts/*.example.json` — примеры контрактов. **Нормативом являются `contracts/*.schema.json`**
  (ADR-022): проза ссылается на схему, примеры валидируются против неё в CI, типы генерируются.
- `assets/*.dot` — редактируемые исходники схем Graphviz.

## Главное изменение относительно v2.0-draft

Выполнен систематический поиск готовых решений по каждому модулю, и он изменил три решения
предыдущей редакции:

1. **Мод строится форком [Satisfactory Build Calculator](https://github.com/AutoCrafter1223/satisfactory-build-calculator-mod)
   (MIT), а не с нуля** (ADR-016). Интерактивный граф, калькулятор, чтение каталога, силовая
   модель, HUD, хоткеи и локализация приходят в v1.0 вместе с базой кода. Версия v1.4,
   существовавшая ради одного интерактивного графа, упразднена.
2. **MCP-сервер переехал из игрового процесса в компаньон** (ADR-017). Мод держит один
   исходящий канал и не слушает ни одного порта; риск R-13 закрыт до реализации.
3. **Ficsit Remote Monitoring исключён из источников кода** (ADR-018). Проверка репозитория:
   файла лицензии нет. Замены найдены — `UModContentRegistry` из SML и MIT-код форка.

Плюс: планировщик решает линейную систему вместо обхода дерева с тремя спецслучаями (ADR-019);
компаньон признан нашим компонентом v1.0 (ADR-020); введено разделение `core/` и `GameFacade/`
с проверкой скриптами CI (ADR-021); перед реализацией любого модуля проверяется наличие
готового средства SML (ADR-023).

Полная сводка изменений с причинами — раздел 17.1 документа. Переход 1.0-draft → 2.0-draft
сохранён в разделе 17.2 как архив.

## Сборка схем и документа

PNG в комплект не входят — исходники `.dot` изменились и требуют перерисовки:

```bash
dot -Tpng -Gdpi=150 assets/components.dot -o assets/components.png
```

```bash
dot -Tpng -Gdpi=150 assets/actions.dot -o assets/actions.png
```

Graphviz здесь — инструмент сборки документации, запускаемый отдельным процессом. Это не
противоречит §18.3, где он отклонён как библиотека: EPL-1.0 несовместима с Apache-2.0 при
линковке, а раскладка графа в игре приходит с форком.

Форматированный документ (ссылки на изображения в `ARCHITECTURE.md` уже проставлены):

```bash
pandoc ARCHITECTURE.md -o FICSIT_AI_Release_Architecture_v3.0.docx
```

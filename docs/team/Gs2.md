## D-2 · Токены стиля, неделя 1

Значения для каркаса V-1 и тестовой страницы S8. Имена и геометрия каркаса взяты из [D-1, §1–4 и §8](../design/D-1-frame.md). Имена ниже одинаковы для веба и UMG. Размеры даны при масштабе интерфейса 100 %.

### Цвета

| Токен | Значение (sRGB) | Применение |
|---|---|---|
| `bg-base` | `#0A1724` | Фон экрана |
| `surface` | `#0E2032` | Полосы статуса и клавиш, панели |
| `surface-raised` | `#122A40` | Рельс, наведение, плашка клавиши |
| `stroke` | `#1E3D59` | Декоративный разделитель, сетка графика |
| `stroke-strong` | `#64829C` | Граница элемента управления, если по ней определяют его положение |
| `accent` | `#F5871F` | Заливка выбранного пункта и основных действий |
| `accent-edge` | `#FFC078` | Светлая полоса выбранного пункта из D-1 |
| `on-accent` | `bg-base` | Текст и иконки на `accent` |
| `info` | `#2FB8DE` | Основной ряд графика, ссылки, информационные метки |
| `ok` | `#46C46B` | Живая телеметрия, активное соединение |
| `warn` | `accent` | Предупреждающий акцент в состоянии компонента |
| `stale` | `#E8C33C` | Метка устаревших данных |
| `error` | `#FF9292` | Метка ошибки |
| `text` | `#E6F0F7` | Основной текст |
| `text-muted` | `#8FA9BF` | Вторичный текст, подписи осей, неактивные статусы |
| `focus` | `#D9CEFF` | Рамка фокуса клавиатуры и геймпада |
| `focus-gap` | `bg-base` | Прослойка между заливкой элемента и рамкой фокуса |

- `focus` рисуется рамкой `focus-width` с прослойкой `focus-offset` цвета `focus-gap`. На тёмных поверхностях видна светлая рамка, на оранжевой заливке видна тёмная прослойка. Заливку при фокусе сохраняем.
- Текст и значимые иконки на тёмных поверхностях используют контрастные цвета из таблицы. Порог для обычного текста — 4,5:1, для значимых границ и рамки фокуса — 3:1. Для графика `stroke` подходит как вспомогательная сетка, `text-muted` — для подписей, `info` — для линии данных.
- Состояние читается по подписи или форме даже без цвета. При загрузке подпись использует `text-muted`. При устаревании последнее известное значение остаётся читаемым в `text-muted`, а метка с возрастом использует `stale`. При отсутствии данных пояснение использует `text-muted`, при ошибке метка использует `error`. Телеметрия и сайдкар сохраняют отдельные метки.

### Типографика

| Токен | Размер / межстрочный интервал | Начертание | Применение |
|---|---|---|---|
| `type-label` | 13 / 18 | 600 | Подпись рельса, метка полосы, подпись клавиши |
| `type-body` | 16 / 24 | 400 | Основной текст и сообщение чата |
| `type-value` | 17 / 24 | 600 | Значение в полосе, числа в сводке |
| `type-title` | 22 / 28 | 600 | Заголовок текущего экрана |

`font-ui` — системный шрифт без засечек для S8, в UMG — соответствующий шрифт интерфейса с латиницей и кириллицей. Для меняющихся значений, таблиц и осей используй цифры одинаковой ширины. Строки v0.1 английские и приходят из UE Localization. Длинные переводы переносятся согласно правилам D-1. Формат чисел берётся из локали, единицы — из [архитектуры, §5.6](../ARCHITECTURE.md).

### Отступы и размеры

| Токен | Значение | Применение |
|---|---|---|
| `space-1` | 4 | Зазор между меткой и значением |
| `space-2` | 8 | Иконка и подпись, соседние компактные элементы |
| `space-3` | 12 | Внутренний отступ компактного компонента |
| `space-4` | 16 | Внутренний отступ панели, отступ иконки рельса сверху |
| `space-5` | 20 | Отступ по периметру экранного модуля и шаг между его панелями по D-1 |
| `space-6` | 24 | Разделение соседних групп |
| `space-8` | 32 | Разделение секций |
| `focus-width` / `focus-offset` | 2 / 2 | Толщина рамки и прослойки фокуса |
| `rail-item-height` / `rail-icon-size` | 76 / 24 | Высота слота при одной строке, сторона иконки |
| `rail-accent-width` | 5 | Ширина светлой полосы активного пункта |

Размеры, межстрочные интервалы и отступы умножаются на единый коэффициент масштаба от 0,8 до 1,5. Плотность меняет отступы внутри экранного модуля, геометрия хоста берётся из D-1. Токены служат входом в проверку S8. Компоненты и их витрина проходят отдельную приёмку по [#34](https://github.com/kkkingqz/ficsit-ai-helper/issues/34).

## D-2 · Компоненты и состояния

Спецификация общая для веба и UMG. Компоновка экранов, порядок сжатия и тексты берутся из [макетов экранов D-1](../design/D-1-screens.md) и [каркаса D-1](../design/D-1-frame.md). Телеметрия и статус связи приходят из [публичного API v0](../interfaces/public-api-v0.md), сообщения — из чата Foreman через адаптер. Компоненты получают готовое состояние от модуля экрана и передают ему действия.

### Основные компоненты

| Компонент | Состав и токены | Поведение |
|---|---|---|
| Плитка метрики | Название `type-label`, значение `type-value`, единица и источник `type-label`. Фон `surface`, отступ `space-3`, зазор между меткой и числом `space-1`. | Форматирует значение по `PrecisionDigits` и локали, единицу берёт из API. Знак виден у отрицательного баланса. `0` отображается числом. Для длинной подписи или единицы допускается дополнительная строка. |
| График ряда | Заголовок `type-label`, оси `text-muted`, сетка `stroke`, легенда с именем, текущим значением и единицей каждого ряда. Внутренний отступ `space-4`. | Использует `Timestamps` для оси времени. Номинальный `IntervalSec` служит метаданными. При неполном окне показывает информационную подпись из D-1 и доступные точки. Ряд из одной точки виден маркером. |
| Таблица | Заголовки `type-label`, ячейки `type-body`, числа выровнены вправо, строки разделены `stroke`. Горизонтальный отступ ячейки `space-2`, вертикальный `space-1`. | Использует тот же формат значений, что плитка. Пропущенная ячейка получает прочерк и доступную подпись об отсутствии значения. Спарклайн показывает форму ряда, а соседняя ячейка содержит число и единицу. |
| Сообщение чата | Автор и время `type-label`, текст `type-body`, отступ `space-3`. Левая полоса `accent` для оператора и `info` для ассистента. | Имя автора различает сообщения даже без цвета. Длинный текст переносится и остаётся доступен прокруткой. Поток дописывает то же сообщение, отмена сохраняет фрагмент с меткой `Stopped`. Ошибка адаптера выводится отдельным блоком. |
| Полосы статуса и клавиш | Фон `surface`. Метки `type-label`, значения `type-value`, плашка клавиши `surface-raised`. Размеры и порядок сжатия из D-1. | Статус телеметрии и статус сайдкара читаются независимо. Горячая клавиша использует текущую привязку ввода. Клавиатурный фокус и выбранный пункт видны одновременно по рамке `focus` и заливке `accent`. |

До четырёх рядов в `timeseries` получают пары «цвет и рисунок» по порядку легенды. Первый — `info` и сплошная линия, второй — `accent` и штрихи, третий — `text` и точки, четвёртый — `text-muted` и штрихпунктир. Легенда повторяет образцы. При смене окна существующие ряды сохраняют пары. Лимит задаёт [архитектура, §7.4](../ARCHITECTURE.md), а выбор и вытеснение рядов — D-1.

Полоса заполнения и карточка объекта используют те же форматы чисел, меток и пустых значений. Длина полосы дополняется текстовым значением. Чип шаблона подставляет текст в поле чата и показывает рамку при фокусе. Сегментированный переключатель выбирает одно окно 5, 15 или 60 минут, его заливка выбора и рамка фокуса видны одновременно. Если в v0.1 войдёт V-14, карточка переиспользует плитку или график. Метки `LIVE SOURCE` и `ASSISTANT ESTIMATE` показывают происхождение, метка свежести остаётся отдельной.

### Состояния данных и ввода

| Состояние | Плитка, график и таблица | Сообщение чата и полосы |
|---|---|---|
| Загрузка | Заголовок и место под результат остаются на месте. Нейтральная подпись `text-muted`, пока источник готовит первый результат. | При ожидании первого фрагмента показывается признак ожидания, при поступлении текста — состояние потока. Действия остаются доступны по правилам экрана. |
| Свежие данные | Значения `text`, источник и время актуальности видны. Снимок обновляет изменившиеся метрики. | Телеметрия `LIVE`, сайдкар `LINKED` по отдельности. Завершённый ответ сохраняет текст, автора и время. |
| Устаревшие данные | Последнее значение той же метрики, области и сессии остаётся видимым в `text-muted`. График сохраняет точки, метка `stale` показывает возраст. | Телеметрия получает `STALE` с возрастом. Состояние сайдкара отражает фактическую связь. Возраст метрик к тексту сообщений не применяется. |
| Нет данных | Плитка показывает прочерк с пояснением, график — сетку с подписью, таблица — одну поясняющую строку. Для пустой фабрики используется отдельный текст из D-1. | Приветствие соответствует успешно загруженной пустой истории. При отключённом сайдкаре видны уже загруженные сообщения. Если история ещё не получена, экран показывает её недоступность. Область отправки показывает инструкцию по подключению. |
| Ошибка | Локализованное пояснение и метка `error` в затронутом компоненте. Последние доступные значения сохраняют указание актуальности. | Ошибка адаптера отображается отдельно от ответа. Повтор доступен, если действие предусмотрено D-1. Прерванный пользователем ответ сохраняет метку `Stopped`. |

- Возраст значения — разница между текущим временем сессии и `SessionTimeSec` значения либо временем последней точки ряда. По умолчанию при возрасте строго больше `max(3 × SampleIntervalSec, 10 с)` значение устарело. Берём интервал отдельной метрики из API и правило [архитектуры, §8.2](../ARCHITECTURE.md). Если в панели есть устаревшее значение, её общая метка показывает устаревание. Возраст выводится локализованной фразой.
- При смене источника, области или сохранения компонент показывает состояние для новой выборки. Возвращение связи меняет доступность отправки в чате независимо от новых снимков телеметрии.
- При переходах между состояниями сохраняются фокус и порядок навигации, пока элемент доступен. Если действие исчезает, экран передаёт фокус ближайшему доступному действию в той же зоне. Длинные подписи переносятся.
- Для длинных списков и таблиц экран задаёт доступную высоту общей панели прокрутки. Заголовок панели остаётся на месте, у таблицы при необходимости закрепляются названия столбцов. Область прокрутки получает фокус, колесо и клавиши прокручивают её. У тонкой полосы дорожка `bg-base` и бегунок `stroke-strong`. Реализация для веб-спайка — в [PR #37](https://github.com/kkkingqz/ficsit-ai-helper/pull/37).
- Все подписи, состояния и шаблоны составных фраз поступают из UE Localization. Возраст передаётся параметром локализованной фразы целиком. `EFicsitAIUnit` преобразуется в подпись по одной таблице локализации для плитки, таблицы, оси, легенды и карточки чата. Числа форматируются по локали. Проверяем длинную подпись и кириллицу при масштабе 150 %.

### Сценарии для витрины на Fixture

При выборе веба витрина использует те же компоненты, что V-5 и V-6. При выборе UMG эти сценарии применяются к экранным компонентам в Screen Lab. Сценарии дополняют [чек-лист Gf2 для v0.1](../../tests/test-plan/acceptance-v01-checklist.md). Реализация Fixture и приёмка остаются в зоне Gf2.

| Сценарий | Что проверить |
|---|---|
| Число и пустое значение | Свежие `0 MW`, отрицательный баланс и значение с дробной частью отличаются от пропуска. Плитка, таблица и легенда одинаково форматируют одну метрику. |
| Два интервала свежести | Метрика с интервалом 2 с свежая в 10 с и устаревает в 11 с. Метрика с интервалом 20 с свежая в 60 с и устаревает в 61 с. Если обоим значениям 11 с, общая метка панели показывает `STALE`. Значения сохраняются, возраст и состояние читаются без цвета. |
| Ряд с неравномерными точками | При точках на 5, 10 и 20 с и номинальном шаге 5 с третья точка остаётся на 20 с. При `bWindowIncomplete` показаны доступные точки и пояснение. Отдельно проверяются пустой ряд и одна точка. |
| Четыре ряда и смена окна | Легенда и линии различимы без цвета. При переключении 5/15/60 мин сохранившиеся ряды сохраняют рисунок и цвет. Пятый ряд обрабатывается экраном согласно D-1. |
| Загрузка, пустая фабрика и ошибка | Для одного набора панелей видны разные пояснения и стабильная геометрия. Ошибка одной панели оставляет остальные читаемыми. |
| Сайдкар отключается при живой телеметрии | Метрики «Статистики» продолжают обновляться. Полосы одновременно показывают `LIVE` и `OFFLINE`. В открытом чате ранее загруженная история видна. При входе без загруженной истории видна недоступность истории и инструкция по подключению. Отдельно проверяется успешно загруженная пустая история с приветствием. |
| Поток, отмена и ошибка чата | Поток дописывает сообщение без дубликатов. После отмены текст остаётся с `Stopped`. Ошибка показывается отдельно, а при V-14 метки источника и актуальности карточки читаются независимо. |
| Масштаб, перевод и ввод | На 1280 × 720 при 150 % длинные подписи и кириллица помещаются или переносятся. С клавиатуры и геймпада видно, где фокус и какой элемент выбран. |

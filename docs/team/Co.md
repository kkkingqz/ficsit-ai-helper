## Резерв и запасной ход

Свободная ёмкость (около трети этапа) — резерв на провал S8 или S2: вендоринг IXWebSocket, доработки BLUI, upstream-PR в Foreman. При варианте UMG Co ведёт ветку UMG в S6 (Screen Lab, 3 ч·д).

## Правила

- Каждый PR в мод проходит ревью Co; для задач Gf это обязательная часть плана.
- Перед началом спайка — чек-лист Gf2 из P-7; работа считается готовой по нему, а не по ощущению.
- Решения по итогам спайков записываются в `ARCHITECTURE.md` на воротах (пишет Co, утверждает King).
- Задержка больше чем на день по задаче критического пути — сразу сообщить Co и King.

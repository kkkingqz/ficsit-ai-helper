Проверить, можно ли писать экраны на вебе и показывать их встроенным браузером BLUI (CEF) из отдельного мода-библиотеки. Ведёт Co. - [ ] Модули `WebSockets` и `HTTP` грузятся в готовой игре под SML — результат в S2
- [ ] BLUI v5.1.0 и CEF 128 — плагин-мод `FicsitAIWebRuntime`, бинарники через `RuntimeDependencies`. Релиз собран под UE 5.8, у игры 5.6.1: исходники ожидаемо собираются без правок, риск — готовая `libcef_dll_wrapper.lib`, собранная более новым MSVC, чем наш 17.8
- [ ] Загрузка в готовой игре; основной мод объявляет библиотеку зависимостью; установка через менеджер модов
- [ ] Локальная страница из каталога мода: обработчик ресурсов для `https://ficsitai.invalid/` и `CefRequestHandler` — своей схемы в BLUI нет, это наш код
- [ ] Мост: `blu_event` → заглушка API → ответ выполнением JavaScript; задержка круга — вместе с Co2
- [ ] Блокировка внешней навигации

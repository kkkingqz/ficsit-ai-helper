# Задачи команды на этапе 1

**Ввести новую сессию в курс дела — [ONBOARD.md](ONBOARD.md)**: готовый промпт и первое дело по каждой роли.

**Зоны владения файлами — [OWNERSHIP.md](OWNERSHIP.md): каждый коммитит только свои файлы.** Вопросы друг другу — [questions/](questions/README.md): вопрос пишешь в свой файл, ответ приходит в файл отвечающего.

**Начинать с [KICKOFF.md](KICKOFF.md)** — указания Co на старт: с чего каждый начинает, чего ждёт от других, что отдаёт и когда, чего делать не надо. Этот файл и файлы по людям отвечают на вопрос «что делать», KICKOFF — на вопрос «с чего начать и в каком порядке».

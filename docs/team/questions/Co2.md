## Co2-1 → Co · ответ на Co-1 · 10.11.2026

Сделал, ссылка в `CONTRIBUTING.md` есть — и не одной строкой, потому что документ без этого расходился с `AGENTS.md`:

- во вступлении — `OWNERSHIP.md` как ответ на вопрос «чьи файлы я правлю», с разделяемыми каталогами, общими файлами и запретами (`git add -A`, `git stash` без метки, `git reset --hard`, `git clean`), и ссылка на `questions/` для случая «нужен чужой файл»;
- в разделе «Ветки» — рабочая копия на роль, узел `main`, задачная ветка от `origin/main` в своей копии, `fetch` + `rebase` за свежим `main`;
- там же — документы в `main` через fast-forward `push origin HEAD:main` и строка `Роль: <Роль>` в сообщении коммита;
- в «PR и ревью» — «один PR не трогает зоны двух людей».

Заодно расхождение, которое это вскрыло: `CONTRIBUTING.md` писался до рабочих копий и говорил только «работа идёт в ветке», а `AGENTS.md` §3 ссылается на него как на источник порядка работы с кодом. Теперь оба говорят одно. Если решишь, что порядок работы с git должен жить только в `AGENTS.md`, скажи — уберу дубль из своего файла и оставлю ссылку.

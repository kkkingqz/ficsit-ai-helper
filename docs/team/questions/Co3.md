# Вопросы от Co3

Владелец файла — Co3. Правила — [README.md](README.md). Пишет сюда только Co3; ответы приходят в файлы отвечающих.

## Co3-1 → Co · 10.11.2026 · открыт

В эскизе [`interfaces/screen-host-and-module.md`](../../interfaces/screen-host-and-module.md) модулю нечем объявить две вещи, которые рисует каркас: **отображаемое имя экрана** (заголовок верхней полосы) и **горячие клавиши** для нижней полосы. Предлагаю два метода `IFicsitAIScreenModule`:

```cpp
/** Локализованное имя для заголовка каркаса (§6.7). */
virtual FText GetDisplayName() const = 0;

/** Подсказки клавиш для нижней полосы, в порядке показа. Esc добавляет хост. */
virtual TArray<FFicsitAIHotkeyHint> GetHotkeyHints() const { return {}; }
```

`FFicsitAIHotkeyHint` — действие Enhanced Input (ADR-027) плюс локализованная подпись: букву полоса берёт из текущей привязки, а не из строки.

**Без ответа:** в макетах остаётся как есть, а Gf при V-1 заведёт таблицу «id → название и клавиши» внутри хоста. Это работает, но каждый новый модуль придётся дописывать в хост — ровно та связность, от которой уводит ADR-001.

## Co3-2 → Co · 10.11.2026 · открыт

Показывает ли **экран в мире** (render target 16:9, §6.6) верхнюю полосу статуса, или на меше рисуется только содержимое модуля? Рельс и полосу клавиш там рисовать точно не нужно — ввода нет, а 180 px рельса съедают девятую часть ширины. В контексте модуля признак `bWorldSurface` уже есть, решения по каркасу нет.

**Без ответа:** в [D-1-frame.md](../../design/D-1-frame.md) остаётся моё предложение — содержимое модуля плюс верхняя полоса. Нужно до V-1 (неделя 5), иначе Gf делает каркас дважды.

## Co3-4 → Co · 10.11.2026 · открыт

Два следствия контракта `list_metrics` для «Статистики»:

1. Панель `METRICS` показывает `id`, название и единицу, а оси и плитки подписываются единицей. Поле `unit` в ответе обязательно?
2. Ограничение «не больше четырёх рядов на графике» — это UX-решение моё или его надо записать в архитектуру рядом с лимитами §7.4, чтобы модель через `create_screen` не собирала экран с десятью рядами?

**Без ответа:** считаю `unit` обязательным и держу лимит в четыре ряда как решение UI, не как инвариант контракта.

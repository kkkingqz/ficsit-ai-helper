# Cf3 — задачи этапа 1

**Профиль** — веб-программист. [План этапа 1](../PLAN-v0.1.md) · [Задачи Cf3](https://github.com/kkkingqz/ficsit-ai-helper/milestone/1?labels=%D0%B8%D1%81%D0%BF%3A%20Cf3) · [Состояние](state/Cf3.md).

## Роль

Источник Save для экранов вне игры, архив сайдкара, данные и выбор метрики и окна для «Статистики». При наличии времени — `show_card`. Каждый PR с твоим кодом проверяет Co2. У Co2 остаются адаптер, нормализатор, вход в Foreman, токены и ключи, лаунчер, фасад API и логика чата.

## Ревью и передача

Co2 проверяет каждый PR, включая сборку архива. Gf2 готовит проверяемые критерии. Gs2 ведёт вёрстку «Статистики» и карточек. Если PR не принят после двух кругов ревью или задача опаздывает больше чем на три дня, она возвращается Co2. Первая на возврат — V-5. [План §8](../PLAN-v0.1.md#8-риски-этапа).

# Назначение и статус

| Поле | Значение |
|---|---|
| Документ | FICSIT AI — Module Registry |
| Версия | 2.0 · 09.11.2026 (заменяет 1.0 от 04.11.2026) |
| Отношение к архитектуре | Подчинённый документ. Источник истины — `ARCHITECTURE.md` редакции **2.2-draft**; здесь — разбиение на модули, готовые решения по каждому и остаток собственной работы. При расхождении прав `ARCHITECTURE.md` |
| Лицензия проекта | GPL-3.0-or-later (ADR-031) |

Документ отвечает на один вопрос: **из каких модулей состоит мод и существует ли для каждого готовое решение.** Для каждого модуля указаны результат поиска, лицензия, статус проверки, остаток собственной работы, версия и ссылки на архитектуру. Отрицательный результат («готового нет, пишем сами») — такой же результат и приводится явно.

**Что изменилось относительно 1.0.** Версия 1.0 писалась под закрытую линию 3.0-draft (ветвь `docs/architecture-3.0-salvage`), где мод строился форком Satisfactory Build Calculator целиком. Реестр пересобран под 2.2-draft:

- **Форка SBC нет.** Из SBC берётся слой данных каталога (v1.0); калькулятор и виджет графа — кандидаты провайдера и UI плана за обёрткой (v1.3). Модули, которые «приходили с форком», стали собственной разработкой или референсом (ADR-013).
- **Сайдкар = vanilla Foreman + тонкий адаптер**, а не единый «компаньон» (ADR-012).
- **Планировщик — обёртка с заглушкой в v1.0**; линейная система — один из кандидатов провайдера v1.3 (ADR-028).
- **Подтверждений игрока нет** — модуль «очередь подтверждений» удалён (ADR-009).
- **Версии модулей приведены к дорожной карте:** экраны и редактор экранов — v1.0, чертежи — v1.1, голос — v1.2, планировщик — v1.3, AI Assistant и HUD — v1.4, логистика — v1.5.
- **Исправлены факты о SML 3.12** (проверено по исходникам 09.11.2026): Mod Key Bind Registry в SML 3.12 нет, Replication Policy не определяет тип сессии.
- Добавлены модули, которых в 1.0 не было: `OperationRegistry`, публичный API, источники данных, Screen Lab, линии, заметки, карточки в чате, интеграция с FicsIt-Networks, библиотека чертежей.

**Статусы проверки.**

| Статус | Значение |
|---|---|
| подтверждено | Проверено по первичному источнику: исходники, файл лицензии, официальная документация. Дата указана, если проверка была позже 04.11.2026 |
| не подтверждено | Решение выбрано, но ключевое свойство не проверено; вынесено в спайк (раздел «Проверки») |
| нет решения | Поиск выполнен, пригодного готового решения нет; модуль пишется самостоятельно |
| своё по решению | Готовое решение не ищется: модуль — ядро продукта или граница доверия |

**Размещение кода** (`ARCHITECTURE.md` §3.2.1, §13): `FicsitAIApi` — интерфейсы и типы контрактов; `FicsitAIUI` — экранные модули без заголовков игры и SML; `FicsitAICore` — всё, что требует игры, в том числе `GameFacade/` (единственное место типов `AFG*`/`UFG*`) и `core/` (логика без Unreal, собирается и на хосте). Колонка «Где» ниже ссылается на эти каталоги.

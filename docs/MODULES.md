| Поле | Значение |
|---|---|
| Документ | FICSIT AI — Module Registry |
| Версия | 1.0 · 04.11.2026 · **частично устарел, см. ниже** |
| Статус | Результат поиска готовых решений. Писался как основание для редакции 3.0-draft, линия которой закрыта |
| Отношение к архитектуре | Подчинённый документ. Источник истины — `ARCHITECTURE.md` редакции **2.2-draft**; здесь фиксируется только разбиение на модули и состояние поиска по каждому |

**Что в этом документе устарело.** Он писался под линию 3.0-draft, где мод строился форком Satisfactory Build Calculator целиком. Ведущей редакцией выбрана 2.2-draft, и четыре его вывода там отвергнуты или изменены:

| Вывод этого документа | Решение 2.2-draft |
|---|---|
| Форк SBC — база мода; модули A1–A6, B1–B3, C5, D1, D8, D9 «приходят с форком» | Из SBC берётся **только слой данных** (v1.0) и калькулятор как кандидат провайдера за `IPlannerProvider` (v1.3). Остальные перечисленные модули — собственная разработка (`ARCHITECTURE.md` §2, ADR-013) |
| «Компаньон» как единый локальный компонент | Терминология уточнена: **сайдкар** = vanilla Foreman + тонкий **адаптер**; адаптер — единственный MCP-сервер Foreman (ADR-012) |
| Транспорт: UE-модули `HTTP`/`WebSockets`, доступность не подтверждена (E1) | Решение то же, но риск ниже: выбор WebSocket или long-poll делается в Spike S2, и есть третий путь — upstream-PR в Foreman на `MCP_EXTRA_URLS` |
| Планировщик в моде, Eigen как основной инструмент | Планировщик **за обёрткой и с заглушкой в v1.0**; линейная система — один из кандидатов провайдера v1.3 (ADR-028) |

| Собственная лицензия — Apache-2.0 | Отменено: **GPL-3.0-or-later** (ADR-031). Лицензионная сводка ниже обновлена |

**Что остаётся в силе и перенесено в архитектуру:** отсутствие лицензии у Ficsit Remote Monitoring; перечень готовых средств SML; `UModContentRegistry` для состава каталога; смерть `vercel/pkg`; лицензионная таблица; сам перечень модулей и статусы проверки по каждому. Разбиение на модули A–H пригодно как чек-лист объёма независимо от того, чем они реализуются.

Документ сохраняется как есть — без правки по строкам, чтобы не выдавать исследование за решение. Актуальные решения смотреть в `ARCHITECTURE.md`.

Документ отвечает на один вопрос: **из каких модулей состоит мод и существует ли для каждого готовое решение.** Для каждого модуля указан результат поиска, лицензия, статус проверки и остаток собственной работы. Отрицательный результат («готового нет, писать самим») — такой же результат и приводится явно.

**Как читать статусы проверки.**

| Статус | Значение |
|---|---|
| подтверждено | Проверено по первичному источнику (репозиторий, файл лицензии, официальная документация) 04.11.2026 |
| не подтверждено | Решение выбрано, но ключевое свойство не проверено; вынесено в спайк §Проверки |
| нет решения | Поиск выполнен, пригодного готового решения не найдено; модуль пишется самостоятельно |
